## เปิดจาก Source Code
- Python 3.10 ขึ้นไป พร้อม Tkinter (แนะนำตัวติดตั้ง Python มาตรฐานจาก python.org)
- ใช้เฉพาะ Standard Library: tkinter, dataclasses, heapq, json, time, csv, argparse
- ไม่ต้องติดตั้งแพ็กเกจภายนอกสำหรับการรัน
- Windows: เปิด `run.bat` หรือใช้ `py -3 app.py`
- macOS/Linux: ใช้ `python3 app.py` โดย Linux อาจต้องติดตั้งแพ็กเกจ `python3-tk` ของระบบ
- โหมดเริ่มด้วยตัวอย่าง: `python app.py --demo`
- ตรวจตรรกะโดยไม่เปิดหน้าต่าง: `python app.py --self-test`

## วิธีใช้งาน
1. กรอกทะเบียนรถ แล้วกด **จองช่องที่ใกล้ที่สุด** ระบบแสดงรหัส R0001 เป็นต้น
2. ระบบเลือกเฉพาะช่องที่ว่างและเข้าถึงได้ ระยะเท่ากันเลือกหมายเลขช่องน้อยกว่า
3. สิทธิ์จองมีอายุ 300 วินาที ใช้รหัสจองหรือทะเบียนยืนยันเข้า
4. กด **ยืนยันเข้า / เปิดไม้กั้น** เพื่อเปลี่ยนเป็นเข้าจอดแล้ว ไม้กั้นเป็นการจำลองด้วยข้อความ
5. กด **บันทึกออกจากลาน** เมื่อรถออก ช่องนั้นจะกลับมาว่าง
6. กด **ยกเลิกการจองล่าสุด** เพื่อยกเลิกรายการที่ยังรอเข้าและจองหลังสุดในหน้าจอผู้ดูแลนี้
7. กด **เร่งเวลา +60 วินาที** หรือ **+5 นาที** เพื่อสาธิตการหมดอายุ โดยรถที่เข้าจอดแล้วไม่หมดอายุ
8. ประวัติแสดง 30 เหตุการณ์ล่าสุด (รวมจอง เข้า ออก ยกเลิก หมดอายุ) รายการที่ 31 เขียนทับรายการเก่าที่สุด
9. กด **ส่งออกประวัติ CSV** เพื่อบันทึกประวัติปัจจุบันก่อนปิดโปรแกรม

เวลาในประวัติเป็นวินาทีสัมพัทธ์จากเริ่มโปรแกรม ไม่ใช่เวลานาฬิกา การเร่งเวลาเพิ่มค่าเวลาจำลองสำหรับทุกการจอง รวมรายการใหม่หลังจากนั้นด้วย
รหัสจองและทะเบียนปรับเป็นตัวพิมพ์ใหญ่และตัดช่องว่าง ทะเบียนต้องมี 1-20 ตัวอักษร และไม่ใช้รูปแบบ `R` ตามด้วยตัวเลขเพื่อป้องกันชนกับรหัสจอง

## Demo แนะนำ
1. เริ่มโปรแกรมใหม่ กด **โหลดตัวอย่าง P1, P2**
2. กรอก `DEMO-003` แล้วจอง ควรได้ P3 ระยะ 22 เมตร ผ่าน Entrance > J1 > J2 > P3
3. ยืนยันเข้าโดยรหัสที่ระบบใส่ให้ สังเกตช่อง P3 เปลี่ยนเป็นสีฟ้า
4. กรอก `DEMO-004` แล้วจอง ได้ P4 กดยกเลิกล่าสุด P4 กลับเป็นสีเขียว
5. จอง `DEMO-005` แล้วกดเร่งเวลา +5 นาที P4 หมดอายุและกลับเป็นสีเขียว P1-P3 ยังคงเข้าจอด
6. ใช้ทะเบียน `DEMO-003` บันทึกออก P3 กลับมาว่าง
7. จองทะเบียนใหม่หลายรายการจนลานเต็ม แล้วลองจองเพิ่ม ระบบต้องแจ้งไม่มีช่องว่าง

## ADT และไฟล์สำคัญ
- `structures.py`: Graph แบบ adjacency list, Dijkstra, IndexedMinHeap, linked Stack, CircularBuffer
- `parking.py`: จัดการสถานะและ Hash Table ด้วย Python dict สำหรับรหัสจอง/ทะเบียน
- `app.py`: หน้าต่าง Tkinter ตรวจหมดอายุทุก 250 ms และรับคำสั่งบน GUI thread เดียว
- `data/parking_graph.json`: กราฟตัวอย่าง 16 จุดยอด 15 เส้นเชื่อมแบบสองทิศทาง หน่วยเมตร
- `data/demo_scenarios.json`: ข้อมูลและผลที่คาดหวังสำหรับการสาธิต
- `tests/test_parking.py`: การทดสอบ 14 กรณี รวมการหมุนเวียน 1,000 รอบและสุ่มคำสั่ง 1,500 ครั้ง
- `build_exe.bat`: วิธีสร้าง Windows EXE จาก Source Code

Min-Heap peek O(1), push/pop/remove O(log R) โดย R คือจำนวนที่ยังจองรอเข้า ไม่ใช่ O(1) สำหรับการนำออก
Stack ใช้ LIFO และมีดัชนีของ node เพื่อถอดรายการที่หมดอายุ/เข้าจอด O(1) ไม่สะสมประวัติไม่จำกัด
Dijkstra คำนวณตอนเริ่มโปรแกรม O((V+E) log V) สำหรับกราฟนี้ แล้วเลือกช่องว่าง O(S) ต่อการจอง S=10
Hash Table ค้นหาเฉลี่ย O(1) แต่กรณีเลวร้าย O(A) เมื่อ A คือรายการที่ยังมีสิทธิ์

## ขอบเขตและข้อจำกัด
เป็นต้นแบบสำหรับผู้ดูแล 1 คน ไม่มีบัญชีแยกผู้ใช้ การยกเลิกใช้รายการล่าสุดของหน้าจอนี้
หนึ่งทะเบียนมีได้หนึ่งสิทธิ์จองหรือเข้าจอด ไม่มีค่าจอด ไม่มีอ่านป้ายทะเบียนจากกล้อง ไม่มีฮาร์ดแวร์ไม้กั้นจริง และไม่มีฐานข้อมูลถาวร
เมื่อโปรแกรมเปิดอยู่และ event loop ทำงาน ระบบตรวจหมดอายุทุก 250 ms และตรวจซ้ำก่อนรับคำสั่ง จึงปฏิเสธการเข้าเมื่อ now >= deadline
หากปิดโปรแกรมหรือเครื่องพักงาน จะไม่มีงานเบื้องหลัง สถานะทั้งหมดเริ่มใหม่เมื่อเปิดอีกครั้ง
ระยะทางเป็นข้อมูลสมมติสำหรับสาธิต ไม่ใช่ผังลานจริง
