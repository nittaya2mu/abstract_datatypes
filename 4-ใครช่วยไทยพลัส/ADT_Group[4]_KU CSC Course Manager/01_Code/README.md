# คู่มือการใช้งานโปรแกรม KU CSC Course Manager

โปรแกรม **KU CSC Course Manager** เป็นระบบจัดการการลงทะเบียนเรียนผ่าน Command Line Interface (CLI) ที่มีหน้าจอแบบ TUI (Text-based User Interface) ซึ่งถูกพัฒนาด้วยไลบรารี ncurses โปรแกรมนี้ช่วยให้นิสิตสามารถดูรายวิชาที่เปิดสอน จัดตารางเรียน เพิ่ม/ถอนรายวิชา และดูแผนผังวิชาบังคับก่อน (Prerequisite) ได้อย่างสะดวกสบาย

---

## 🛠️ การติดตั้งไลบรารี การคอมไพล์ และการรันโปรแกรม

โปรแกรมนี้พัฒนาด้วยภาษา C และใช้ไลบรารี **`ncurses`** เพื่อสร้างหน้าจอแสดงผลแบบ Text-based User Interface (TUI) ในคอนโซล/เทอร์มินัล 

---

### 💻 1. สำหรับ Windows

เนื่องจากบน Windows มาตรฐานไม่มีไลบรารี `ncurses` ติดตั้งมาด้วย แนะนำให้ใช้ผ่าน **MSYS2** (แนะนำ) หรือ **WSL (Windows Subsystem for Linux)**:

#### วิธีที่ 1: ติดตั้งผ่าน MSYS2 (แนะนำ)
1. **ดาวน์โหลดและติดตั้ง MSYS2:**
   - ดาวน์โหลดตัวติดตั้งได้จากเว็บไซต์ทางการ: [https://www.msys2.org/](https://www.msys2.org/)
   - ติดตั้งตามขั้นตอนปกติ
2. **เปิดเทอร์มินัล MSYS2 UCRT64** (ค้นหาใน Start Menu: `MSYS2 UCRT64`)
3. **ติดตั้ง Toolchain (GCC) และไลบรารี ncurses:**
   ```bash
   pacman -Syu
   pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-ncurses
   ```
   *(หากใช้สภาพแวดล้อม MINGW64 ให้ใช้คำสั่ง: `pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-ncurses`)*
4. **นำทางไปยังโฟลเดอร์โปรเจกต์:**
   ```bash
   cd /c/Users/YourUsername/Downloads/Mini_Project_ADT
   ```
5. **คอมไพล์โปรแกรม:**
   ```bash
   gcc main_ncurses.c -o main_ncurses.exe -lncursesw
   ```
   *(หากใช้ `-lncursesw` ไม่ผ่าน ให้เปลี่ยนเป็น `-lncurses`)*
6. **รันโปรแกรม:**
   ```bash
   ./main_ncurses.exe
   ```

#### วิธีที่ 2: ติดตั้งผ่าน WSL (Ubuntu / Debian บน Windows)
1. เปิด Ubuntu บน Windows Terminal
2. ติดตั้ง GCC และ ncurses:
   ```bash
   sudo apt-get update
   sudo apt-get install build-essential libncurses5-dev libncursesw5-dev
   ```
3. คอมไพล์และรัน:
   ```bash
   gcc main_ncurses.c -o main_ncurses -lncursesw
   ./main_ncurses
   ```

---

### 🍎 2. สำหรับ macOS (Apple Silicon M1/M2/M3/M4 & Intel)

macOS มีคอมไพเลอร์ Clang/GCC ผ่าน Xcode Command Line Tools และสามารถติดตั้ง ncurses เวอร์ชันสมบูรณ์ผ่าน **Homebrew**:

1. **ติดตั้ง Xcode Command Line Tools (หากยังไม่เคยติดตั้ง):**
   ```bash
   xcode-select --install
   ```
2. **ติดตั้งไลบรารี ncurses ผ่าน Homebrew:**
   ```bash
   brew install ncurses
   ```
3. **นำทางไปยังโฟลเดอร์โปรเจกต์:**
   ```bash
   cd ~/Downloads/Mini_Project_ADT
   ```
4. **คอมไพล์โปรแกรม:**
   - **กรณีใช้ ncurses จาก Homebrew (แนะนำสำหรับรองรับ UTF-8 / กราฟิกกรอบ):**
     ```bash
     gcc main_ncurses.c -o main_ncurses -I$(brew --prefix ncurses)/include -L$(brew --prefix ncurses)/lib -lncurses
     ```
   - **หรือกรณีคอมไพล์ด้วยไลบรารีมาตรฐานของระบบ:**
     ```bash
     gcc main_ncurses.c -o main_ncurses -lncurses
     ```
5. **รันโปรแกรม:**
   ```bash
   ./main_ncurses
   ```

> ⚠️ **คำแนะนำสำหรับ macOS:** แนะนำให้ใช้โปรแกรม **Terminal** หรือ **iTerm2** โดยขยายขนาดหน้าต่าง Terminal ให้กว้างอย่างน้อย 80 คอลัมน์ x 25 บรรทัดขึ้นไป เพื่อให้หน้าจอ TUI แสดงผลกรอบและสีสันได้อย่างถูกต้องสวยงาม

## 🚀 การเริ่มต้นใช้งาน (Getting Started)

เมื่อเปิดโปรแกรมขึ้นมา (`main_ncurses.exe`) คุณจะพบกับหน้าจอเมนูเข้าสู่ระบบ:

1. **Login to existing account** - สำหรับผู้ที่มีบัญชีอยู่แล้ว ให้กรอก Username และ Password
2. **Register new account** - สำหรับผู้ใช้ใหม่ ให้กรอก Username และ Password เพื่อสมัครสมาชิก (ระบบจะตรวจสอบว่า Username ซ้ำหรือไม่)
3. **Exit Program** - ออกจากโปรแกรม

> **หมายเหตุ:** ข้อมูลผู้ใช้จะถูกบันทึกไว้ในไฟล์ `users.txt` และข้อมูลการลงทะเบียนเรียนจะแยกตามผู้ใช้ในไฟล์ `student_<username>.txt`

## ⌨️ การควบคุมพื้นฐาน (Navigation & Controls)

โปรแกรมออกแบบมาให้ใช้งานด้วยคีย์บอร์ดเป็นหลัก:
- `ลูกศรขึ้น (Up)` / `ลูกศรลง (Down)` : ใช้เพื่อเลื่อนเลือกเมนูหรือเลื่อนดูรายการ (Scroll)
- `Enter` : ยืนยันการเลือกหรือยืนยันข้อมูลที่กรอก
- `ตัวเลข 1-7` : ใช้เป็นคีย์ลัดเพื่อเลือกเมนูในหน้า Main Menu อย่างรวดเร็ว
- `Q` หรือ `ESC` : ใช้สำหรับย้อนกลับ (Back), ยกเลิก (Cancel) หรือออกจากเมนู
- `Backspace` : ใช้ลบตัวอักษรเมื่ออยู่ในหน้าต่างกรอกข้อความ

## 📋 เมนูหลัก (Main Menu)

เมื่อเข้าสู่ระบบสำเร็จ คุณจะพบกับเมนูหลัก 7 รายการ พร้อมกับแถบแสดงหน่วยกิต (Credits) ที่ลงทะเบียนไปแล้ว (สูงสุด 22 หน่วยกิต)

### 1. View Available Courses (ดูรายวิชาที่สามารถลงทะเบียนได้)
- ระบบจะแสดงรายวิชาทั้งหมดที่คุณ **มีคุณสมบัติ** สามารถลงเรียนได้ (ผ่านวิชาบังคับก่อน, เวลาไม่ชนกับวิชาที่ลงแล้ว, หน่วยกิตไม่เกินกำหนด และยังไม่เคยเรียนผ่าน)
- ใช้ปุ่มลูกศรเพื่อเลื่อนดูรายการ
- **การลงทะเบียน:** หากต้องการลงวิชาใด สามารถกด `Enter` ที่วิชานั้นเพื่อลงทะเบียน (Enroll) ได้ทันที

### 2. View My Timetable (ดูตารางเรียน)
- แสดงตารางเรียนประจำสัปดาห์ของคุณ (จันทร์ - อาทิตย์)
- แบ่งออกเป็นช่วงเช้า (Morning: 09.00 - 12.00) และช่วงบ่าย (Afternoon: 13.00 - 16.00)
- ช่องตารางจะแสดงรหัสวิชา, ชื่อวิชา และชื่อผู้สอน
- ช่วยให้เห็นภาพรวมของเวลาว่างและวิชาที่เรียนในแต่ละวันได้อย่างชัดเจน

### 3. Add Course (เพิ่มรายวิชา)
- พิมพ์ **รหัสวิชา (Course ID)** ที่ต้องการลงทะเบียน
- ระบบจะทำการตรวจสอบเงื่อนไขต่างๆ อย่างเข้มงวด:
  - พบรหัสวิชานี้หรือไม่
  - ผ่านวิชาบังคับก่อน (Prerequisite) แล้วหรือยัง
  - เวลาเรียนชนกับวิชาอื่นหรือไม่ (Time conflict)
  - หน่วยกิตรวมเกิน 22 หน่วยกิตหรือไม่
- หากผ่านเงื่อนไข ระบบจะเพิ่มวิชานั้นเข้าตารางเรียนทันที

### 4. Drop Course (ถอนรายวิชา)
- พิมพ์ **รหัสวิชา** ที่ต้องการถอน
- เมื่อถอนสำเร็จ หน่วยกิตและช่วงเวลาของวิชานั้นจะถูกคืนกลับมา ทำให้สามารถลงวิชาอื่นแทนได้

### 5. Recommend Courses (แนะนำการลงทะเบียนเรียน)
- ฟีเจอร์สุดชาญฉลาดที่ช่วยจัดชุดวิชาที่เหมาะสมที่สุดให้คุณ
- ระบบจะให้คุณเลือก **สาขาวิชา (Major)** ที่คุณสนใจ
- จากนั้นระบบจะคำนวณหาวิชาที่เกี่ยวข้องกับสาขานั้น (หรือวิชาศึกษาทั่วไป) ที่คุณสามารถลงได้ โดยจัดชุดวิชา (Bundle) ที่ทำให้คุณได้หน่วยกิตเต็มประสิทธิภาพมากที่สุดเท่าที่โควตาจะเหลืออยู่
- วิชาที่ระบบแนะนำจะแสดงเป็นบรรทัดสีเขียวพร้อมแท็ก `[YES]`

### 6. Prerequisite Map (แผนผังวิชาบังคับก่อน)
- แสดงลำดับโครงสร้างรายวิชาทั้งหมดว่าต้องเรียนวิชาใดก่อนหลัง (Topological Sort)
- แสดงข้อมูลวิชาที่บังคับให้ผ่านก่อน (Prereq) และวิชาที่ปลดล็อกเมื่อเรียนผ่าน (Unlocks)
- มีสีบอกสถานะความคืบหน้าของคุณ:
  - **สีเขียว [Done]** : เรียนผ่านแล้ว
  - **สีฟ้า [Enrolled]** : กำลังลงทะเบียนเรียนอยู่
  - **สีเทา [Not taken]** : ยังไม่ได้เรียน

### 7. Logout & Exit (ออกจากระบบ)
- ทำการบันทึกข้อมูลทั้งหมด ออกจากระบบผู้ใช้ปัจจุบัน และกลับสู่หน้าจอ Login

---

## 📂 โครงสร้างข้อมูลเบื้องหลัง (Data Files)
- `courses.txt` / `data_*.txt` : เก็บข้อมูลรายวิชาทั้งหมดของมหาวิทยาลัย
- `users.txt` : เก็บข้อมูลรหัสผ่านสำหรับการยืนยันตัวตน
- `student_<ชื่อผู้ใช้>.txt` : เก็บประวัติรายวิชาที่เรียนผ่านแล้ว (COMPLETED) และที่กำลังลงทะเบียนอยู่ (ENROLLED) ของผู้ใช้นั้นๆ

> **💡 คำแนะนำ:** หมั่นเช็ค View Available Courses และ Prerequisite Map ควบคู่กันไป เพื่อวางแผนการเรียนไม่ให้ติดวิชาบังคับในเทอมถัดๆ ไป!
