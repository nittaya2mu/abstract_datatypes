เกี่ยวกับโปรเจกต์
--------------------------------------------------------------------------------
Console Application บริหารวัตถุดิบในตู้เย็น: แจ้งเตือนของใกล้หมดอายุ,
ค้นหา/จัดการด้วยรหัส และแนะนำเมนูที่เคลียร์ของใกล้หมดอายุได้มากที่สุด
ข้อมูลบันทึกลงไฟล์อัตโนมัติ ใช้งานต่อเนื่องข้ามการปิด-เปิดโปรแกรมได้


โครงสร้างข้อมูลและความซับซ้อน
--------------------------------------------------------------------------------
1. Stack (ShelfStack)        จำลองชั้นวาง ของใหม่อยู่บนสุด หยิบก่อนของเก่า
                             Push / Pop / Peek = O(1)
2. Min-Heap (ExpiryMinHeap)  ของใกล้หมดอายุที่สุดอยู่ Root เสมอ
                             Push / Pop = O(log n), Top = O(1)
3. BST (FoodBST)             ค้นหา/เพิ่ม/ลบด้วย ID จัดการหน่วยความจำ malloc/free
                             Search / Insert / Delete = O(log n) เฉลี่ย
4. Greedy (greedySuggestCombos)
                             เลือกเมนูที่เคลียร์ของใกล้หมดอายุได้หลายชนิดสุดก่อน (Max-Coverage)


ไฟล์ในโปรเจกต์
--------------------------------------------------------------------------------
  main1.cpp / main1.c      โปรแกรมหลัก (C++17 / C99)
  run_app.bat              คอมไพล์และเปิดโปรแกรมบน Windows
  fridge_data.txt          ฐานข้อมูล (สร้างอัตโนมัติ พร้อมข้อมูลเริ่มต้น 5 รายการ)
  timing_template.c        กิจกรรมที่ 2: วัดเวลาค้นหา
  run_timing_eval.bat      รัน Benchmark บน Windows
  data_1000/10000/100000.txt   ชุดข้อมูลทดสอบ

  รูปแบบข้อมูล: ID|Name|Category|ExpiryDate(YYYY-MM-DD)|Quantity|ShelfNo

วิธีใช้งาน
--------------------------------------------------------------------------------
Windows (เร็วสุด) : ดับเบิลคลิก run_app.bat

Terminal :
  g++ -std=c++17 -o fridge main1.cpp        (C++)
  gcc -std=c99   -o fridge main1.c          (C)
  ./fridge          (Windows: fridge.exe)
  ./fridge --test   รัน Self-Check 6 ชุด (วันที่/Leap Year, Stack, Min-Heap,
                    BST, Greedy, String Sanitization)

เมนูหลัก
  1 เพิ่มของ        2 แสดงทั้งหมด        3 ของต้องรีบกิน + เมนูแนะนำ (Min-Heap)
