--------------------------------------------------------------------------------
ประยุกต์ใช้โครงสร้างข้อมูลแบบ Abstract Data Type (ADT)
--------------------------------------------------------------------------------
1. 3D Array                 จำลองผังอาคารจอดรถ 3 ชั้น (Floor x Col x Row)
                            ระบุนโยบายการจอด (ชั้น 1: ผู้พิการ/ผู้สูงอายุ, ชั้น 2-3: ทั่วไป)
2. Priority Queue (Heap)    คัดสรรและเสนอช่องจอดที่ว่างและใกล้ทางเข้ามากที่สุด O(log N)
3. Queue (FIFO)             จัดการคิวรถรอเข้าจอดบริเวณทางเข้าเมื่อลานจอดเต็ม
4. Hash Table               ค้นหาพิกัดตำแหน่งจอดรถจากหมายเลขทะเบียน ได้ใน O(1)
5. Graph + Dijkstra         คำนวณและนำทางเส้นทางเดินรถที่สั้นที่สุดไปยังช่องจอด
6. Stack (LIFO)             บันทึกประวัติการเข้า-ออก สำหรับย้อนกลับรายการ (Undo/Redo)

--------------------------------------------------------------------------------
วิธีใช้งานโปรแกรม (ตรวจสอบสถานะลานจอดรถ)
--------------------------------------------------------------------------------
เมื่อเปิดโปรแกรม จะพบกับเมนูหลัก (Main Menu):

1. Search ด้วยป้ายทะเบียน              [ค้นหาตำแหน่ง + คำนวณค่าปรับสะสม]
2. Add รถ (จัดสรรช่องจอดอัตโนมัติ)       [เลือกประเภทผู้ใช้ + จัดช่องจอดตามสิทธิ์]
3. Remove รถ (นำรถออก + คิดค่าปรับ)    [ออกใบเสร็จ + คืนพื้นที่ช่องจอด]
4. Edit รถ                           [แก้ไขป้ายทะเบียน / ประเภทผู้ใช้]
5. แสดงที่จอดรถ                       [แสดงผังลานจอด 3D Real-time ทุกชั้น]
6. ทดสอบจับเวลา (Benchmark)          [วัดเวลา Sequential Search เทียบ Big-O]
7. Exit                              [ออกจากโปรแกรม]



--------------------------------------------------------------------------------
ชุดทดสอบและการวัดประสิทธิภาพ (Benchmark) ในโปรแกรมหลัก (ตรวจสอบสถานะลานจอดรถ)
--------------------------------------------------------------------------------
ระบบมีฟังก์ชันวัดประสิทธิภาพการค้นหา (Sequential Search / Hash Search)
โดยทำการวนค้นหาซ้ำ (1,000 รอบ) เพื่อจับเวลาจริงเปรียบเทียบกับทฤษฎี Big-O

ผลการวัดเวลา Sequential Search (การค้นหาแบบลำดับ):
n = 1,000   : เวลาเฉลี่ย 0.000620 ms
n = 10,000  : เวลาเฉลี่ย 0.004720 ms (เพิ่มขึ้น ~7.61 เท่า)
n = 100,000 : เวลาเฉลี่ย 0.037320 ms (เพิ่มขึ้น ~7.91 เท่า)
สรุป : ประสิทธิภาพการทำงานจริงสอดคล้องกับ Big-O Notation ระดับ O(N)

วิธีคอมไพล์และรันโปรแกรมรอง (วัดเวลาในการค้นหาจากข้อมูลทดสอบ)
--------------------------------------------------------------------------------
เปิด terminal ในโฟลเดอร์ที่มีไฟล์ซอร์สโค้ด

Windows (PowerShell / CMD) :
    gcc timing_template.c -o timing
    timing.exe data_1000.txt targets_1000.txt
    timing.exe data_10000.txt targets_10000.txt
    timing.exe data_100000.txt targets_100000.txt

Linux / macOS :
    gcc timing_template.c -o timing -lm
   ./timing data_1000.txt targets_1000.txt
   ./timing data_10000.txt targets_10000.txt
   ./timing data_100000.txt targets_100000.txt

หมายเหตุ: 
1.  หากมีการดึงโมดูล Hash Table หรือ AVL Tree จากโฟลเดอร์หลักร่วมด้วย ให้ระบุไฟล์เพิ่ม เช่น
    gcc timing_template.c ../hashtable.c ../avltree.c -I.. -o timing -lm
2.  บน Linux/macOS เติม -lm เพื่อลิงก์ไลบรารี math.h
