1. โปรแกรมนี้ทำอะไร
------------------------------------------------------------
ระบบจองตั๋วเรือโดยสารเส้นทางภูเก็ต-เกาะพีพี-รัษฎา ฯลฯ ทำงานผ่านเมนูบน terminal
ออกแบบให้ใช้โครงสร้างข้อมูลแบบ Abstract Data Type (ADT) ที่เขียนขึ้นเอง
ทั้งหมด ไม่ใช้ library โครงสร้างข้อมูลสำเร็จรูป

  ADT ที่ใช้             หน้าที่ในระบบ
  --------------------   ------------------------------------------------
  Graph + Dijkstra       ผังท่าเรือและเส้นทาง หาเส้นทางที่เร็วที่สุด
                         (ท่าเรือ = Node, เส้นทางเดินเรือ = Edge มีน้ำหนัก)
  Queue (FIFO)           คิวจองตามลำดับก่อน-หลัง และออกบัตรขึ้นเรือ
  Priority Queue (Heap)  คิวสำรอง (Waitlist) เมื่อที่นั่งเต็ม
                         จัดลำดับตามสิทธิ์: ตั๋วด่วน > ผู้สูงอายุ > ทั่วไป
  Hash Table             ค้นหาตั๋วจากรหัสการจอง เร็วแบบ O(1) เฉลี่ย
  AVL Tree               เก็บรหัสการจองแบบเรียงลำดับ ค้นหา O(log n)
  Stack (LIFO)           ประวัติการทำรายการ สำหรับ Undo (ย้อนรายการล่าสุด)

2. สิ่งที่ต้องมีก่อนรัน (Requirements)
------------------------------------------------------------
  - ภาษา       : C มาตรฐาน C99
  - Compiler   : gcc (Windows ใช้ MinGW-w64 / MSYS2, Linux/Mac ใช้ gcc หรือ clang)
  - Library    : ไม่ต้องติดตั้งเพิ่ม ใช้เฉพาะ standard library ของ C
  - ตัวช่วย    : make (ไม่บังคับ ถ้าไม่มีให้ใช้คำสั่ง gcc ตรงๆ ตามข้อ 3)
  - Editor     : ใช้ VS Code หรืออะไรก็ได้ที่เปิด terminal ได้

ตรวจสอบว่าติดตั้ง gcc แล้ว: พิมพ์  gcc --version  ใน terminal

ไฟล์ข้อมูล (Data Files):
  ไม่มีไฟล์ข้อมูลภายนอก ข้อมูลตัวอย่าง (ท่าเรือ เส้นทาง ตารางเดินเรือ)
  ฝังอยู่ในไฟล์ data.c โปรแกรมโหลดให้อัตโนมัติตอนเริ่มทำงาน
  (ถ้าต้องการแก้ข้อมูล เช่น เวลาเรือ ให้แก้ที่ data.c แล้วคอมไพล์ใหม่)

3. วิธีคอมไพล์และรันโปรแกรมหลัก
------------------------------------------------------------
เปิด terminal ในโฟลเดอร์ที่มีไฟล์ main.c (ตรวจสอบตำแหน่งให้ถูกก่อน)

[วิธี A] ใช้ gcc ตรงๆ  (ใช้ได้ทุกระบบ แนะนำสำหรับ Windows)

  Windows (PowerShell):
      gcc -std=c99 -Wall -Wextra main.c booking.c graph.c pqueue.c queue.c stack.c hashtable.c avltree.c data.c -o ferry -lm
      .\ferry.exe

  Linux / Mac:
      gcc -std=c99 -Wall -Wextra main.c booking.c graph.c pqueue.c queue.c stack.c hashtable.c avltree.c data.c -o ferry -lm
      ./ferry

[วิธี B] ใช้ make  (Linux / Mac / Windows ที่ติดตั้ง make)

      make          คอมไพล์
      make run      คอมไพล์แล้วรันเลย
      make debug    คอมไพล์พร้อมตัวตรวจ memory error (AddressSanitizer)
      make clean    ลบไฟล์ที่คอมไพล์ออก

  หมายเหตุ: บน Windows ที่ใช้ PowerShell ธรรมดา คำสั่ง make clean อาจใช้ไม่ได้
  (เพราะเรียกคำสั่ง rm) ให้ใช้วิธี A แทน

4. วิธีใช้งานโปรแกรม
------------------------------------------------------------
เมื่อรันจะเห็นเมนูหลัก พิมพ์ตัวเลขแล้วกด Enter

   1. แสดงผังท่าเรือและเส้นทางทั้งหมด
   2. ค้นหาเส้นทางที่เร็วที่สุด              [Graph + Dijkstra]
   3. จองตั๋ว                               [Queue / Priority Queue]
   4. ค้นหาตั๋วจากรหัสการจอง                [Hash Table]
   5. แสดงรายการจองทั้งหมด (เรียงรหัส)      [AVL Tree]
   6. ยกเลิกการจอง
   7. ยกเลิกรายการล่าสุด (Undo)             [Stack]
   8. แสดงคิวสำรอง (Waitlist)
   9. สถิติ Hash Table
  10. ตารางเดินเรือ (ชนิดเรือ/รอบเวลา/วันให้บริการ)
  11. คิวขึ้นเรือ / ออกบัตรตามลำดับจอง      [Queue FIFO]
  12. ล้างรายการที่ยกเลิกออกจากดัชนี        [AVL + Hash delete]
  13. เทียบความเร็วค้นหา Hash vs AVL
   0. ออกจากโปรแกรม

ตัวอย่างการจองตั๋ว (เมนู 3): ระบบจะถามทีละขั้น เลือกจากตัวเลขในรายการ
  ขั้น 1 เลือกท่าต้นทาง -> ขั้น 2 เลือกปลายทาง -> ขั้น 3 เลือกวันเดินทาง
  -> ขั้น 4 เลือกเที่ยวเรือ -> ขั้น 5 ประเภทผู้โดยสาร -> ขั้น 6 กรอกชื่อ/ยืนยัน
  ระบบจะแสดงเฉพาะตัวเลือกที่เป็นไปได้จริง (ท่าที่มีเรือวิ่ง วันที่มีเรือออก)
  ทุกขั้นพิมพ์ 0 เพื่อยกเลิกการจอง

ข้อจำกัดของระบบ: เก็บรายการจองได้สูงสุด 500 รายการ (MAX_BOOKINGS ใน booking.h)

5. ชุดทดสอบและการวัดประสิทธิภาพ (เป็นโปรแกรมแยกจากโปรแกรมหลัก)
------------------------------------------------------------
คอมไพล์แต่ละตัวด้วยคำสั่งด้านล่าง แล้วรันไฟล์ที่ได้ (Windows ใช้ .\ชื่อ.exe)

  test_adt.c    ทดสอบความถูกต้องของ ADT ทุกตัว (ข้อมูลปริมาณมาก)
                ผลที่คาดหวัง: ผ่าน 34 / ล้มเหลว 0
      gcc -std=c99 -Wall -Wextra test_adt.c booking.c graph.c pqueue.c queue.c stack.c hashtable.c avltree.c data.c -o test_adt -lm

  test_edge.c   ทดสอบกรณีขอบ: โครงสร้างว่าง, ข้อมูลเดียว, Undo คืนที่นั่ง
                ผลที่คาดหวัง: ผ่าน 53 / ล้มเหลว 0
      gcc -std=c99 -Wall -Wextra test_edge.c booking.c graph.c pqueue.c queue.c stack.c hashtable.c avltree.c data.c -o test_edge -lm

  benchmark.c   วัดเวลาจริงของแต่ละ ADT ที่ 3 ขนาดข้อมูล เทียบกับ Big-O
      gcc -std=c99 -O2 -Wall -Wextra benchmark.c graph.c pqueue.c stack.c hashtable.c avltree.c data.c -o benchmark -lm

  space_bench.c วิเคราะห์หน่วยความจำ (Space Complexity) จาก sizeof ของ struct
      gcc -std=c99 -Wall -Wextra space_bench.c booking.c graph.c pqueue.c queue.c stack.c hashtable.c avltree.c data.c -o space_bench -lm

  ถ้าผลลัพธ์ยาวจนหน้าจอ terminal แสดงไม่ครบ ให้บันทึกลงไฟล์แล้วเปิดดู:
      cmd /c "benchmark.exe > benchmark_result.txt"

6. โครงสร้างไฟล์
------------------------------------------------------------
  main.c              เมนูหลักและการรับ-แสดงผลทาง terminal
  booking.c / .h      ระบบหลัก เชื่อม ADT ทั้งหมดเข้าด้วยกัน (จอง/ยกเลิก/Undo/Waitlist)
  graph.c / .h        Graph (adjacency list) + Dijkstra + ที่นั่งแบบ bitmap
  hashtable.c / .h    Hash Table (chaining, ตาราง 100003 ช่อง)
  avltree.c / .h      AVL Tree (ต้นไม้ค้นหาแบบสมดุล)
  pqueue.c / .h       Priority Queue (Min-Heap)
  queue.c / .h        Queue (linked list, FIFO)
  stack.c / .h        Stack (linked list, LIFO)
  data.c / .h         ข้อมูลตัวอย่าง: ท่าเรือ เส้นทาง ชนิดเรือ ตารางเวลา
  types.h             ชนิดข้อมูลกลาง (Booking, ค่าคงที่)
  Makefile            สคริปต์คอมไพล์
  test_adt.c          ชุดทดสอบความถูกต้อง
  test_edge.c         ชุดทดสอบกรณีขอบ
  benchmark.c         วัดเวลา (Time Complexity)
  space_bench.c       วัดหน่วยความจำ (Space Complexity)

7. ปัญหาที่พบบ่อย
------------------------------------------------------------
  - ตัวอักษรไทยเพี้ยนเป็นขยะ (Windows)
      โปรแกรมตั้งค่า console เป็น UTF-8 ให้อัตโนมัติแล้ว ถ้ายังเพี้ยน

      ยังไม่ได้ติดตั้ง gcc หรือยังไม่ได้เพิ่มลง PATH
  - พิมพ์ .\ferry.exe แล้วไม่เกิดอะไร
      เช็คว่าไม่มีจุดหรืออักขระเกินท้ายชื่อไฟล์

การทดสอบประสิทธิภาพด้วยชุดข้อมูลของอาจารย์ (โฟลเดอร์ timing_test)
------------------------------------------------------------
โฟลเดอร์ timing_test เก็บชุดข้อมูลทดสอบกลางของรายวิชา 01204212
  - data_*.txt, targets_*.txt, README.md  : ไฟล์ของอาจารย์ ไม่ได้แก้ไข
  - timing_template.c                      : โปรแกรมวัดเวลาของอาจารย์ ที่กลุ่มแก้ให้เรียก
                                             Hash Table และ AVL Tree ของโปรเจกต์
                                             (ทุกจุดที่แก้มีคอมเมนต์ [กลุ่มแก้] กำกับ)

วิธีคอมไพล์และรัน (พิมพ์ในโฟลเดอร์ timing_test)
  gcc timing_template.c ../hashtable.c ../avltree.c ../data.c -I.. -o timing.exe
  .\timing.exe data_1000.txt targets_1000.txt
  .\timing.exe data_10000.txt targets_10000.txt
  .\timing.exe data_100000.txt targets_100000.txt

  (บน Linux/macOS ใช้ -o timing และรันด้วย ./timing)

ผลที่ต้องได้ทุกขนาด: Hash และ AVL "พบ 7 ไม่พบ 3" และตำแหน่งตรงกับ Sequential
ตามกติกา ให้รันขนาดละ 5 ครั้ง ตัดค่าสูงสุดและต่ำสุด แล้วเฉลี่ย 3 ค่าที่เหลือ

ความเข้ากันได้กับคอมไพเลอร์
------------------------------------------------------------
โค้ดทั้งหมดคอมไพล์ผ่านทั้งแบบ C99 และ C89/C90 (gcc รุ่นเก่า เช่นใน Dev-C++ 5.11
ที่ค่าเริ่มต้นเป็น gnu90) โดยไม่ต้องใส่ -std=c99 และไม่ต้องตั้งค่าคอมไพเลอร์เพิ่ม
(ตัวแปรลูปถูกประกาศภายในบล็อก { int i; for (i = 0; ...) } แทนแบบ for (int i = 0; ...))
