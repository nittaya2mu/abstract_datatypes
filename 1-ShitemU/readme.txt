หมายเหตุ จำเป็นต้องใช้ภาษาอังกฤษเป็นหลักเพราะภาษาไทยในเครื่องที่ทดลองมีปัญหาจึงเป็นภาษาเอเลี่ยนครับ

ภาษาที่ใช้: ภาษา C (C Standard Core)
Compiler: GCC หรือ Clang (รองรับทั้ง Windows, macOS และ Linux)

Libraries ที่ใช้: standard C Libraries พื้นฐาน (ไม่ต้องติดตั้งเพิ่มเติม)
<stdio.h>, <stdlib.h>, <string.h>, <time.h>
Windows: <conio.h>, <windows.h>
Linux / macOS: <unistd.h>, <termios.h>, <fcntl.h>

ขั้นตอนการติดตั้งและการเปิดใช้งานโปรแกรม
1. การคอมไพล์โปรแกรม (Compilation)
เปิด Terminal หรือ cmd ในโฟลเดอร์โครงการ แล้วใช้คำสั่ง GCC เพื่อรวมไฟล์ทั้งหมด:
gcc main.c game.c puzzle.c display.c adt.c -o sudoku
./sudoku    

เมนูหลัก (Main Menu)
1. Play Game (เล่นเกม): เริ่มเลือกขนาดกระดาน ระดับความยาก และเข้าสู่โหมดการเล่น
0. Exit (ออกจากโปรแกรม): ปิดการทำงานของเกม
move คือ การเลือกตัวที่จะตอบโดย Rowคือแนวนอน และ Colคือแนวตั้ง และval คือคำตอบ // วิธีเล่นหรือตอบ เช่น 2 5 6
highlight คือ การโฟกัสกับแนวตั้งและแนวนอนในตัวที่เราต้องการจะดูเช่น hl 4 3 (โดยได้ตัวอย่างการทำมาจาก sudoku.com )
history คือ การเช็คประวัติการเดินทั้งหมด
reset คือ รีเซ็ตกระดาน หรือ สร้างกระดานใหม่
0 คือ กลับไปที่เมนู

โดย4x4มีแค่โหมดเดียวคือเล่นแบบปกติ
และ9x9 มีทั้งหมด 3 โหมด
โหมดที่1 easy มีเวลาให้ 8 นาที เมื่อตอบถูกจะได้เวลาเพิ่ม 8 วินาที และเมื่อตอบผิดจะลดเวลาลง 5 วินาที และมีโบนัสถ้าตอบถูฏติดกัน 3 ข้อ จะได้การสุ่มตอบฟรี 1 ครั้ง
โหมดที่2 medium มีเวลาให้ 6 นาที เมื่อตอบถูกจะได้เวลาเพิ่ม 7 วินาที และเมื่อตอบผิดจะลดเวลาลง 6 วินาที และมีโบนัสถ้าตอบถูฏติดกัน 6 ข้อ จะได้การสุ่มตอบฟรี 1 ครั้ง
โหมดที่3 hard มีเวลาให้ 5 นาที เมื่อตอบถูกจะได้เวลาเพิ่ม 5 วินาที และเมื่อตอบผิดจะลดเวลาลง 7 วินาที และไม่มีโบนัสพิเศษ 
โดยทุกโหมดเมื่อตอบผิดเกิน3ครั้งจะแพ้ทันที

run and compile timing_group
gcc timing_group.c -o timing
.\timing.exe data_1000.txt targets_1000.txt
.\timing.exe data_10000.txt targets_10000.txt
.\timing.exe data_100000.txt targets_100000.txt

main.c	จุดเริ่มต้นโปรแกรม ตั้งค่า seed สุ่มตัวเลข แสดงเมนูหลัก (1 = เล่น, 0 = ออก) แล้วเรียก playGame() เมื่อเลือกเล่น
game.h / game.c ควบคุมการเล่นเกมทั้งหมด: เลือกขนาดกระดานและความยาก กำหนดเวลา/โบนัส/บทลงโทษของแต่ละโหมด วนลูปเกมหลักล
ที่นับเวลาถอยหลังแบบ real-time, อ่านคำสั่งจากคีย์บอร์ดโดยไม่ต้องกด Enter ก่อน ตรวจคำตอบ, หักเวลาเมื่อตอบผิด, เพิ่มเวลาเมื่อตอบถูก และตัดสินแพ้/ชนะ
