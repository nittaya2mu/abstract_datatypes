# ผลตรวจโปรแกรม C — กลุ่ม 10

- GUI Win32 และ CLI คอมไพล์ด้วย C11 สำเร็จ มีเฉพาะโค้ด C ในชุดส่ง
- self-test ผ่าน: Hash reuse, indexed Heap, โดเมน, deadline/capacity, 1,000cycles และ 1,500คำสั่งสุ่ม
- คำสั่ง Demo FIFO/การหมดสิทธิ์/เริ่มใช้งาน/Undo/คืนเครื่องหรือช่อง ผ่าน (demo_c.txt)
- ไฟล์กลางอาจารย์ครบ11ไฟล์ SHA-256 ตรงต้นฉบับ
- Hash เทียบ Sequential Search ครบ30targets: พบ7ไม่พบ3ต่อขนาด
- local15runs, REPEAT1,000,000 คงที่; เฉลี่ยตัดปลาย ratio/k ถูกต้อง
- ปฏิเสธข้อมูลผิด10กรณีก่อนจับเวลา รวมจำนวนเต็มเกินขอบเขตและtokenยาวผิดรูปแบบ
- ผล local ไม่ใช้แทนเครื่องกลาง และไม่ใช้จัดอันดับความเร็ว
- ยังต้องทดสอบเครื่องอื่น/เครื่องห้องปฏิบัติการ วัดเครื่องกลางโดยปิดโปรแกรมอื่น และคัดลอกทุกไฟล์ลงUSBจริง
- โค้ดฉบับนี้อยู่ใน repository อาจารย์; ยังไม่ได้ส่ง Classroom หรืออีเมล
