## 1. ระบบนี้ทำอะไร
จัดคิวผู้ใช้เครื่องซักผ้าหอพัก (10 เครื่อง) ตามความเร่งด่วน (priority 1 = ซักด่วน, 2 = รอปกติ)
และเวลาที่เข้าคิว (มาก่อนได้ก่อนในกลุ่ม priority เท่ากัน) จัดเครื่องว่างให้อัตโนมัติ
และจัดผู้ใช้ใหม่เมื่อเครื่องเสีย มี 2 รูปแบบการใช้งาน:
- **SmartLaundry.exe** — หน้าต่างโปรแกรม (GUI) สำหรับ Windows
- **laundry** — เมนูบนเทอร์มินัล ใช้ได้ทุกระบบ และเป็นตัวที่ใช้วัดเวลาตามเงื่อนไขของรายวิชา

ทั้งสองแบบใช้ตรรกะชุดเดียวกัน (`laundry_core.c`)

## 2. โครงสร้างข้อมูลที่ใช้ (เขียนเองทั้งหมด ไม่ใช้ qsort/bsearch)
| โครงสร้าง | ใช้ทำอะไร |
|---|---|
| Priority Queue (Min Heap) | จัดคิวผู้ใช้ตาม (priority, เวลาเข้าคิว) |
| Array | เก็บข้อมูลเครื่องซักผ้า และทะเบียนผู้ใช้ (เรียงตามรหัสเสมอ) |
| Binary Search | ค้นหาเครื่อง / ผู้ใช้ |
| Sorting | Merge Sort (เรียงข้อมูลทดสอบ), Insertion Sort (แสดงคิว) |

## 3. สิ่งที่ต้องใช้ในการรัน
- ภาษา C (C99 ขึ้นไป) และคอมไพเลอร์ **gcc** (MinGW บน Windows) หรือ clang
- **ไม่ต้องติดตั้ง library เพิ่ม** (เวอร์ชัน GUI ใช้ Win32 API ที่มากับ Windows)
- เวอร์ชัน GUI: Windows 10/11 เท่านั้น · เวอร์ชันเมนู: Windows / macOS / Linux
- เทอร์มินัลควรรองรับ UTF-8 เพื่อแสดงภาษาไทย (บน Windows โปรแกรมตั้ง UTF-8 ให้เอง)

## 4. การคอมไพล์
เปิดเทอร์มินัลในโฟลเดอร์ `01_Code`

**Windows (MinGW)** — ดับเบิลคลิก `build_windows.bat` หรือพิมพ์:
```
gcc -Wall -Wextra -o laundry.exe laundry_console.c laundry_core.c
gcc -O2 -Wall -o SmartLaundry.exe laundry_gui.c laundry_core.c -mwindows -lcomctl32 -lgdi32 -lshell32 -lole32
```
**Windows (Visual Studio, Developer Command Prompt)** :
```
cl /utf-8 /O2 laundry_gui.c laundry_core.c user32.lib gdi32.lib comctl32.lib shell32.lib ole32.lib /link /SUBSYSTEM:WINDOWS
cl /utf-8 laundry_console.c laundry_core.c
```
**macOS / Linux (เมนูอย่างเดียว)** — `./build_unix.sh` หรือ
```
gcc -Wall -Wextra -o laundry laundry_console.c laundry_core.c
```

## 5. วิธีเปิดใช้งาน
### 5.1 หน้าต่างโปรแกรม (SmartLaundry.exe)
เปิด `SmartLaundry.exe` (ควรวางไว้ในโฟลเดอร์ `01_Code` เพื่อให้พบโฟลเดอร์ `data`)
- คลิกที่ช่องเครื่องเพื่อเลือกเครื่อง แล้วกด **ซักเสร็จ** หรือ **แจ้งเครื่องเสีย / ซ่อมเสร็จ**
- กรอกรหัส ชื่อ และเลือกประเภท แล้วกด **เข้าคิว** (หรือกด Enter) ระบบจัดเครื่องว่างให้อัตโนมัติ
- **เดินเวลา +5 / +15 นาที** เดินเวลาจำลอง เครื่องที่ซักครบเวลาจะว่างและเรียกคิวถัดไปเอง
- **โหลดสถานการณ์ตัวอย่าง** ตั้งสถานการณ์สาธิต (เครื่อง 3–10 เสีย → คนด่วนแซงคิว → เครื่องเสียกลางคัน)
- **ค้นหาผู้ใช้ด้วยรหัส** ใช้ Binary Search บนทะเบียนผู้ใช้
- **วัดเวลาค้นหา (C)** ทดสอบ Sequential vs Binary Search ด้วยข้อมูลกลาง (ถ้าไม่พบโฟลเดอร์ `data` จะให้เลือกโฟลเดอร์)
- **ล้างระบบ** เริ่มใหม่ทั้งหมด

### 5.2 เมนูบนเทอร์มินัล
```
./laundry                 # เปิดโปรแกรมแบบเมนู (Windows: laundry.exe)
./laundry data            # ระบุโฟลเดอร์ข้อมูลทดสอบล่วงหน้าให้เมนู 8
./laundry < demo/demo_input.txt     # รันสถานการณ์ตัวอย่างอัตโนมัติ
```
เมนู: 1 เพิ่มผู้ใช้เข้าคิว · 2 ซักเสร็จ · 3 แจ้งเครื่องเสีย · 4 แจ้งซ่อมเสร็จ · 5 ค้นหาเครื่อง (Binary Search)
· 6 ค้นหาผู้ใช้ (Binary Search) · 7 แสดงคิวและสถานะเครื่อง · 8 ทดสอบจับเวลาด้วยข้อมูลกลาง · 9 Exit

## 6. ไฟล์ข้อมูล (โฟลเดอร์ data/)
ชุดข้อมูลทดสอบกลางของรายวิชา: `data_N.txt` (ไม่เรียง), `data_N_sorted.txt` (เรียงแล้ว), `targets_N.txt`
สำหรับ N = 1000, 10000, 100000 รูปแบบ: บรรทัดแรกคือจำนวนข้อมูล ตามด้วยค่าจำนวนเต็มบวกไม่ซ้ำคั่นด้วยช่องว่าง
ไฟล์ `targets_N.txt` มีรูปแบบเดียวกัน (ค่าที่ใช้ค้นหา 10 ค่า: พบ 7 ไม่พบ 3)

## 7. การทดลองวัดเวลา
เลือกเมนู 8 (หรือปุ่ม **วัดเวลาค้นหา (C)**) โปรแกรมจะตรวจความถูกต้องก่อน (ต้องพบ 7 ค่า ไม่พบ 3 ค่าในทุกขนาด)
แล้ววัดเวลา Sequential Search (ข้อมูลไม่เรียง) และ Binary Search (ข้อมูลเรียงแล้ว) ขนาดละ 5 ครั้ง
ตัดค่าสูงสุด/ต่ำสุด เฉลี่ยจาก 3 ค่าที่เหลือ ใช้ `REPEAT = 1000` (ปรับได้ที่ `#define REPEAT` ใน `laundry_core.h`)
เวลาที่จับไม่รวมการอ่านไฟล์ การเรียงข้อมูล และการแสดงผล
**สำหรับการวัดบนเครื่องกลาง แนะนำให้ใช้เวอร์ชันเมนู (`laundry`)** เพราะเปิดง่ายและไม่มีงานวาดหน้าต่างรบกวน

## 8. ไฟล์ในโฟลเดอร์นี้
- `laundry_core.h`, `laundry_core.c` — ตรรกะของระบบ (Min Heap, Binary Search, Sorting, จัดคิว, วัดเวลา)

- `laundry_gui.c` — เวอร์ชันหน้าต่าง Windows
- `build_windows.bat`, `build_unix.sh` — สคริปต์คอมไพล์
- `data/` — ข้อมูลทดสอบ · `demo/demo_input.txt` — สถานการณ์ตัวอย่างสำหรับเวอร์ชันเมนู
